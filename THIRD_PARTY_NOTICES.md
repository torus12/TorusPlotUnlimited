# Third-Party Notices

TorusPlot (Copyright (c) 2026 Torus Washington LLC) uses the open-source packages
below at runtime. They are installed from PyPI by the launcher; TorusPlot does not
modify or redistribute them. Each package remains under its own license, and each
installed package carries its own license text in its `*.dist-info` folder.

This file is generated by `python tools/check_licenses.py --notices`. Versions are the
ones pinned in `requirements-lock.txt` (the authoritative list; where two versions are
shown, the lock file selects one by Python version). Licenses are read from each
package's metadata, with hand-verified entries from `tools/license_overrides.yaml`.

## Components bundled inside binary wheels

Some PyPI wheels contain third-party native libraries or carry several license texts.
Each such wheel was reviewed by hand (recorded in `tools/license_overrides.yaml`,
section `bundled_review`); the license gate fails if a new one appears unreviewed.
Wheels differ between Windows, macOS and Linux, so the gate runs on each CI platform.

| Package | Finding |
|---|---|
| charset-normalizer | MIT package. "LGPL" appears only in its README text, in a sentence about the history of a different project (chardet). No LGPL code is included. |
| et-xmlfile | MIT package. "GPL" appears only in the bundled Python Software Foundation license text (history section, "GPL-compatible"), reproduced because parts derive from CPython's ElementTree. No GPL code is included. |
| matplotlib | Matplotlib license (PSF-based). The wheel bundles FreeType, which is dual-licensed "FTL OR GPL-2.0-or-later": the permissive FreeType License (FTL) option applies. Also bundles Agg and Qhull under permissive licenses. |
| numpy | BSD-3-Clause package. The wheel bundles OpenBLAS (BSD-3-Clause) and GCC runtime libraries: libgfortran (GPL-3.0-or-later WITH GCC-exception-3.1; the exception permits use by proprietary programs) and libquadmath (LGPL-2.1-or-later; separate, replaceable shared library). Not redistributed by TorusPlot. See DECISIONS.md D-007. |
| pandas | BSD-3-Clause package. "GPL" appears only inside the Python Software Foundation license text that pandas reproduces for vendored CPython-derived code: its history section says Python releases are "GPL-compatible" and that this "doesn't mean that we're distributing Python under the GPL". No GPL code is included. |
| pillow | MIT-CMU (HPND-style) package. The wheel bundles image libraries under permissive licenses (libjpeg-turbo, zlib, libpng, libtiff, libwebp, OpenJPEG, Little CMS, FreeType under its FTL option, liblzma under 0BSD, and others). GPL/LGPL appear in its license file only as (a) FreeType's alternative license and (b) a note about license texts for xz command-line tools, which are not in the wheel. On Linux the wheel does not include libimagequant (GPL) or FriBiDi (LGPL); the Windows and macOS wheels are checked by the gate on those CI platforms. |
| scipy | BSD-3-Clause package. Same bundled GCC runtime libraries as NumPy (libgfortran under GPL-3.0-or-later WITH GCC-exception-3.1; libquadmath under LGPL-2.1-or-later) plus OpenBLAS (BSD-3-Clause). The wheel's license file reproduces the GPL/LGPL texts for those components. Not redistributed by TorusPlot. See DECISIONS.md D-007. |
| typing-extensions | PSF-2.0 package. "GPL" appears only in the history section of the PSF license itself ("GPL-compatible doesn't mean that we're distributing Python under the GPL"). |

TorusPlot does not ship any of these files: they are downloaded from PyPI onto the
user's computer by the launcher. See DECISIONS.md (D-007) and
docs/COMMERCIAL_RELEASE_CHECKLIST.md for what changes if TorusPlot is ever distributed
as a single frozen installer that bundles the wheels.

## Bundled fonts

Inter, Source Sans 3 and Liberation Sans are bundled unmodified under the SIL Open Font
License 1.1 (OFL-1.1). The license texts ship next to the font files; see
`torusplot/plot/fonts/README.md`.

## Test-only and developer tools (not shipped, not installed by the launcher)

`requirements-dev.txt` lists tools used only to develop and validate TorusPlot: pytest,
pytest-cov, ruff, pip-licenses, hypothesis, and two independent statistics libraries
(lifelines, scikit-posthocs) that the test-suite uses to cross-check TorusPlot's own
implementations.
